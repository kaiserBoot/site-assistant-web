# site-assistant-web

「案件助手 / Site Assistant」App 的公開網站——隱私權政策、使用條款、支援頁面，供 App Store／Google Play 上架與 App 內連結使用。

## 頁面

- `index.html` — 首頁
- `privacy.html` — 隱私權政策
- `terms.html` — 使用條款
- `support.html` — 支援 / FAQ
- `app-ads.txt` — 廣告聯播網授權宣告（目前尚未申請廣告帳號，先留空佔位）

## 部署

純靜態頁面，透過 GitHub Pages 發布（Settings → Pages → Deploy from branch `main` / root）。
